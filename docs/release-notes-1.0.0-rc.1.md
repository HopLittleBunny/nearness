Nearness is now ready for founder testing on Apple Silicon Macs.

This release includes the encrypted local vault, WhatsApp and Apple Messages imports, vCard identity resolution, relational-self and atlas views, research-informed relationship portraits, optional evidence-bound OpenAI analysis, and capacity-aware Care.

Start with the [founder test guide](https://github.com/HopLittleBunny/nearness/blob/main/docs/FOUNDER_TEST.md).

Important: this release is not yet signed or notarized with an Apple Developer ID. macOS will show the unidentified-developer warning; Control-click the app and choose **Open** for founder testing. Broad public distribution remains gated on Apple signing/notarization.

The framework is research-informed and experimental—not clinical or psychometrically validated. Nearness does not rank friends or infer diagnosis, attachment style, toxicity, intent, personality or relationship quality from message sentiment/volume.
