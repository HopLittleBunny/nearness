# Founder test guide

## Install

1. Open the Nearness DMG and drag Nearness to Applications.
2. For an unsigned founder build, Control-click Nearness → Open and confirm once.
3. In **System Settings → Privacy & Security → Full Disk Access**, enable Nearness before linking Messages.

## First useful session (20–40 minutes)

1. Add one WhatsApp export and confirm which participant name is yours.
2. Link 5–20 Messages conversations rather than importing everything immediately.
3. Add a vCard export if several people appear as phone numbers.
4. Review every cross-source identity proposal; deliberately reject one ambiguous name match.
5. Define your closeness language, current chapter and realistic weekly capacity.
6. Open 3–5 people who matter and set bond system, closeness, form, trajectory and intention.
7. Add missing-channel context such as “we mostly call” or “silence is normal here.”
8. For one person, inspect the AI payload sample and run a portrait only if the selection feels acceptable.
9. Open evidence for at least one observation and mark it true or needing context.
10. Open Care and confirm that only people with an intention appear.

## Adversarial checks

- A quiet inner-circle friend should not be moved outward automatically.
- A frequent logistics contact should not be labelled close.
- Choosing rest, boundary or conclude should remove reconnect suggestions.
- Group-carried friends should not be called weak because direct messages are sparse.
- Family should not inherit friendship cadence language.
- Name-only identity matches should never merge automatically.
- Cancel an import and confirm no source appears.
- Import the exact same WhatsApp file twice and confirm duplication is blocked.
- Remove a source, export the archive and delete the complete vault.

## Feedback worth recording

- Where did an observation feel illuminating versus invasive?
- Which missing channel changed the interpretation most?
- Which labels felt natural or awkward?
- Did Care reduce guilt or create it?
- What would make this worth opening again next week?

Do not file real chat excerpts in public issue trackers. Use paraphrases or synthetic examples.
