# Changelog

## 1.0.0-rc.4 — 2026-08-28

- Replace the orphan-prone Electron WhatsApp dialog promise with a standard file input.
- Start local parsing only after a real ZIP or TXT file is selected.
- Add byte-based WhatsApp preview coverage and a 250 MB safety limit.
- Replace the fictional portrait constellation with a data-bound, multi-world relationship atlas.
- Restore profile, identity review, Private AI, source management, privacy controls and relationship context as focused sheets behind two primary destinations.
- Make Care populate from user intentions and rebuild after relationship context changes.
- Require explicit decisions for ambiguous dates and two-sender groups.
- Merge updated and renamed WhatsApp exports without double-counting earlier messages.
- Keep vCard contacts as identity references until message history connects them to a relationship.
- Add resumable schema migrations and batched message writes for large histories.
- Bind every optional AI run to the exact redacted payload the user approved.

## 1.0.0-rc.3 — 2026-08-24

- Attach WhatsApp and Contacts file choosers to the Nearness window.
- Keep Add chats visible when file selection is cancelled.
- Do not create an import/loading modal until a real file is selected.

## 1.0.0-rc.2 — 2026-08-24

- Rebuilt the product around a calm, editorial My world and Care experience.
- Made Add chats the primary entry point and put WhatsApp first.
- Added an end-to-end WhatsApp TXT import regression test.
- Prevented unrelated group messages from contaminating person-level evidence.
- Added exact, recursively redacted OpenAI consent payload inspection.
- Improved tablet responsiveness and relationship-story navigation.

## 1.0.0-rc.1 — 2026-08-24

- First founder-testable macOS desktop release.
- Encrypted local vault and macOS secure-key storage.
- WhatsApp, Apple Messages and vCard imports.
- Cross-source identity review.
- Relational-self, atlas, family, groups, story and people workspaces.
- Evidence-bound optional OpenAI portraits and questions.
- Intention- and capacity-based Care.
- Export, per-source removal and complete local deletion.
